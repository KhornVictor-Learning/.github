## 📌 About The Program

The **Year 4 Engineering (I4) curriculum** in the **Department of Information and Communication Engineering (GIC)** bridges low-level system engineering with high-level enterprise architecture and modern full-stack web platforms. 

Students develop mastery across distributed computing paradigms, enterprise software engineering, database systems, networking layers, compiler construction, and modern web application development.

3. **Practice Quizzes & Flashcards**: Use the `quiz_prep.md` files for spaced-repetition questions and exam practice.
4. **Lab Exercises**: Review practical problem sets and source code before laboratory exams.
